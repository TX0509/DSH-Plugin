# 交付前检查表

## 通用

- [ ] 环境自检跑过，缺的依赖装上了或已告知用户。
- [ ] 用户问的三件事（产物 / 音色 / 素材口径）确认过，没有自作主张。
- [ ] 所有数字、日期、引文、归属都能在用户材料或已核实来源里找到。
- [ ] 正文与卡片文案过了一遍 `humanizer-zh`，空话删了、事实和立场没动。
- [ ] 素材许可与来源写进了页面「图片来源与许可」表与 `assets/SOURCES.md`。

## 网页

- [ ] 图片全部加载（`naturalWidth > 0`），且原图分辨率大于显示尺寸。
- [ ] 桌面 1440 / 移动 390 都看过；TOC 可开合；无横向溢出。
- [ ] 没有重复段落（升格行号错位会重复）。
- [ ] 页脚没有工具品牌署名。
- [ ] PDF 无整页空白，长图高度合理。

## 小红书 / 公众号

- [ ] 每张 3:4 内容覆盖 ≥75% 高度，没有中段大空洞。
- [ ] 标题不贴边、不撞页脚；正文 ≥24px、标注 ≥28px。
- [ ] 画面上没有比例/尺寸标注，没有配对预览图混进交付物。
- [ ] `validate-social-deck` 0 fail（advisory 警告要在交付说明里解释）。
- [ ] 封面与内容页视觉一致（同一主题、同一套字体）。

## 视频

- [ ] 有音轨（`audio:"required"` 导出，verification 里 audio 项 passed）。
- [ ] 配音是用户选的音色；句间有停顿；没有连读成一串。
- [ ] 第 0 帧是钩子，不是黑屏。
- [ ] 文字全部在 168–1330px 安全区，底部 590px 只有装饰。
- [ ] `mcs check <工程目录>` 0 error；`complete_generation` 通过。
- [ ] `mcs verify <mp4> --expect-dur <秒> --expect-cues scenes.json`：时长吻合、积分响度/真峰达标、语句落点对齐（不给 `--expect-cues` 时要明确知道「语句落点未校验」）。
- [ ] 从成品抽帧核对过画面（不是看工程截图）。
- [ ] 发布文案（标题/正文/话题/合规提示）一并交付。

## 交付说明要写的

- 产物路径与规格（尺寸、帧率、时长、音色）。
- 素材许可与该署名的地方。
- 未验证项：例如宿主没有编辑器面板时，说明「成片按文件验证交付，编辑器未呈现」。
- 可选后续：配乐、横版、短版、换音色。
